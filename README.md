# 💰 MoneyWise

O **MoneyWise** é um projeto de **gestão financeira pessoal** desenvolvido para ajudar usuários a controlar suas finanças de forma simples e eficiente. A aplicação permite registrar, acompanhar e gerenciar receitas e despesas, oferecendo uma visão clara da situação financeira.

## 🚀 Tecnologias utilizadas

### Frontend

* **Angular**
* **Tailwind CSS**

### Backend

* **Java**

## ✨ Funcionalidades

* 📊 Cadastro e gerenciamento de receitas e despesas.
* ✏️ Edição e exclusão de registros financeiros.
* 👤 Sistema de autenticação e login de usuários.
* 🔒 Controle de acesso para que cada usuário visualize apenas seus próprios dados.

## 🌐 Deploy

* **Frontend:** hospedado no **Vercel**.
* **Backend:** hospedado no **Railway**.

## 🎯 Objetivo

O objetivo do **MoneyWise** é oferecer uma plataforma intuitiva para organização financeira, permitindo que os usuários acompanhem seus gastos e ganhos, auxiliando no controle do orçamento pessoal e na tomada de decisões financeiras.
